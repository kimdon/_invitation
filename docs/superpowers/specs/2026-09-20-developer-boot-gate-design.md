# Developer Boot Gate Design

## Goal

개발자 모드에서는 웨딩 구동 로그가 끝나기 전까지 커버와 콘솔만 표시하고, 마지막 SUCCESS 로그가 출력된 뒤 후속 초대장 내용을 공개한다.

## Behavior

- 일반 모드는 처음부터 모든 기존 섹션을 표시한다.
- 개발자 모드 진입 시 `booting` 상태로 시작한다.
- `booting` 동안 커버 뒤의 일반 섹션, AI 리뷰, 푸터를 숨긴다.
- 마지막 SUCCESS 로그 출력 후 400ms가 지나면 `ready` 상태로 전환한다.
- `ready` 전환 시 후속 섹션을 450ms 페이드인한다.
- 자동 스크롤은 추가하지 않는다.
- 움직임 최소화 환경에서는 대기시간과 페이드 없이 즉시 `ready`가 된다.
- 일반 모드로 돌아오면 상태를 `idle`로 초기화한다.

## Verification

- 자동 테스트로 초기, 부팅, 준비 상태와 개발자 모드 한정 CSS를 확인한다.
- 실제 브라우저에서 부팅 중 후속 섹션이 숨겨지고 SUCCESS 후 표시되는지 확인한다.
- 일반 모드, 움직임 최소화, 폭죽, 갤러리 설정을 회귀 검증한다.
