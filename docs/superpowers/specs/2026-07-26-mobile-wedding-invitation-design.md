# 모바일 청첩장 디자인 명세

## 목표

첨부된 `모바일 청첩장.pdf`와 제공 HTML을 기준으로, 최대 너비 430px의 정적 모바일 청첩장을 구현한다. PDF가 사용하는 샘플 문구와 사진 자리표시자를 그대로 사용하고, 브라우저에서 동작하는 달력, D-day, 갤러리, 지도 연결을 제공한다.

## 화면 구조

화면은 아이보리색 단일 열이며 다음 순서를 유지한다.

1. 표지: 영문 제목, 날짜, 아치형 대표 사진 자리표시자, 이름, 예식 정보
2. Invitation: 초대 문구와 양가 부모·신랑·신부 이름
3. When & Where: 예식 일시와 장소
4. 2026년 11월 전체 달력: 1일부터 30일까지 표시하고 21일을 원형으로 강조
5. Gallery: 50개 사진 자리표시자를 9개씩, 6페이지로 표시
6. Location: 예식장명, 주소, 지도, 카카오맵·네이버지도 버튼, 교통·주차 정보
7. Thanks to: 안내 문구와 신랑측·신부측 계좌 카드
8. 푸터: 신랑·신부 이름과 `Thank you`

## 시각 기준

- 본문 최대 너비: 430px
- 페이지 배경: `#e8e6e1`
- 카드 배경: `#faf8f4`
- 보조 카드 배경: `#f4f1e8`
- 본문 글자: `#3a372f`
- 골드 포인트: `#b3a985`, `#7d7458`
- 서체: Gowun Batang, Noto Serif KR, Cormorant Garamond
- 대표 이미지 프레임: 290x378px, 상단 아치형
- 섹션 간 여백과 구분선은 제공 HTML의 수치를 유지한다.
- 430px 이하에서는 화면 너비에 맞게 축소하되 가로 스크롤을 만들지 않는다.

## 동작

- 달력은 코드로 생성하며 2026년 11월의 1일부터 30일까지 모두 표시한다.
- D-day는 사용자의 로컬 날짜와 2026-11-21 사이의 날짜 차이를 계산한다.
- 갤러리는 이전·다음 버튼과 페이지 점으로 이동한다.
- 지도 영역은 PDF와 같은 약도 자리표시자를 유지한다.
- 카카오맵·네이버지도 버튼은 예식장 검색 결과를 새 탭으로 연다.
- 지도 SDK와 API 키 설정은 현재 범위에서 제외한다.

## 오류 처리와 접근성

- 모든 버튼에는 식별 가능한 레이블을 제공하고 키보드로 조작할 수 있다.
- 장식 애니메이션은 `prefers-reduced-motion`에서 비활성화한다.
- 외부 지도 링크는 새 탭으로 열고 `noopener noreferrer`를 사용한다.

## 검증 기준

- 자동 테스트가 달력의 전체 날짜, D-day 계산, 지도 URL과 SDK URL 생성을 검증한다.
- 정적 서버에서 430px 모바일 뷰포트로 전체 페이지를 캡처한다.
- 캡처를 PDF와 대조해 섹션 순서, 폭, 배경색, 간격, 글꼴 계층, Location, Thanks to를 확인한다.
- 브라우저에서 갤러리 이동과 외부 지도 링크를 확인한다.
