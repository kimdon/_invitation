# Git 용어 색상 강조 설계

## 목표

개발자 모드 `Invitation` 문구의 Git 용어에서 밑줄을 제거하고 색상 강조만 유지한다.

## 변경 범위

- `.invitation[data-mode="developer"] .developer-term` 규칙에서 밑줄 관련 속성만 제거한다.
- 기존 터미널 파란색과 글자 굵기는 유지한다.
- Git 용어 마크업, 문구, 일반 모드 스타일은 변경하지 않는다.

## 검증 기준

- 개발자 모드의 Git 용어가 기존 파란색으로 표시된다.
- Git 용어에 `text-decoration` 밑줄 스타일이 적용되지 않는다.
- 기존 자동화 테스트와 문법 검사가 모두 통과한다.
