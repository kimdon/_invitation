# Arched Cover and Display Type Design

## Goal

일반 모드의 메인 사진과 영문 이름을 제공된 참고 이미지의 분위기에 맞춘다. 개발자 모드의 레이아웃과 타이포그래피는 변경하지 않는다.

## Visual Design

- 메인 사진은 청첩장 좌우에 24px의 흰 여백을 둔다.
- 사진 상단은 폭의 절반을 기준으로 한 반원형 아치로 자르고 하단은 직선으로 유지한다.
- 기존 흑백 커버 사진과 현재 세로 크기, 이미지 크롭 기준은 유지한다.
- 사진 아래 `Byung-kwan`, `&`, `Do-eun`은 참고 이미지처럼 획 대비가 큰 이탤릭 디스플레이 세리프체를 사용한다.
- 서체는 `Didot`, `Bodoni Moda`, `Bodoni MT` 순서의 스택을 사용하고, 사용할 수 없는 환경에서는 세리프체로 대체한다.
- 날짜와 나머지 본문 글꼴은 변경하지 않는다.

## Scope

- 일반 모드의 `.cover`, `.cover__media`, `.cover__name`, `.cover__ampersand` 스타일만 수정한다.
- HTML 구조, 사진 파일, 개발자 모드, 다른 섹션은 변경하지 않는다.

## Verification

- 자동 테스트로 일반 모드의 좌우 여백, 상단 아치, 이탤릭 세리프 서체를 확인한다.
- 390px 모바일 미리보기에서 아치가 좌우 대칭이고 가로 스크롤이 생기지 않는지 확인한다.
- 개발자 모드 진입 후 기존 커버 표시가 유지되는지 확인한다.
