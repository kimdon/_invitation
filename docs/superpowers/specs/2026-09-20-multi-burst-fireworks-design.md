# Multi-burst Fireworks Design

## Goal

APPROVE 버튼을 누르면 작은 단일 폭발 대신 화면 여섯 지점에서 큰 다색 폭죽이 약 2.5초 동안 순차적으로 터지게 한다.

## Interaction

- 폭발 지점은 좌상단, 우상단, 중앙, 좌하단, 우하단, 하단 중앙으로 분산한다.
- 각 폭발은 충분히 큰 속도와 입자 크기를 사용해 주변 문구를 일부 덮을 수 있다.
- 여섯 폭발은 약 260ms 간격으로 시작되어 서로 겹치며 연속적인 축하 장면을 만든다.
- 애니메이션은 하나의 캔버스와 하나의 `requestAnimationFrame` 루프만 사용한다.
- 새 실행 전 기존 프레임과 캔버스를 정리해 중복 누적을 막는다.
- `prefers-reduced-motion: reduce`에서는 캔버스 애니메이션 없이 승인 메시지만 표시한다.

## Implementation

- `src/invitation.js`에 여섯 지점과 지연시간을 가진 불변 폭발 계획을 둔다.
- `src/app.js`는 경과시간에 따라 계획된 폭발을 하나씩 생성하고 모든 입자를 한 프레임 루프에서 갱신한다.
- 불꽃은 기존보다 큰 속도, 이동 거리, 선 굵기를 사용하며 기존 잔상 감쇠 방식을 유지한다.
- APPROVE 버튼의 비활성 시간은 전체 연출 시간에 맞춘다.

## Verification

- 자동 테스트로 폭발 지점 수, 화면 분산 범위, 순차 지연, 단일 프레임 루프 및 움직임 최소화 처리를 확인한다.
- 320px, 390px, 430px 화면에서 캔버스가 화면 전체를 덮고 가로 넘침이 없는지 확인한다.
- 연속 두 번 실행해 캔버스가 하나만 존재하고 두 번째 연출이 정상 시작되는지 확인한다.
