# AI 리뷰 개별 승인 설계

## 목표

개발자 모드에서 각 AI 리뷰를 한 번씩만 승인할 수 있게 하고, 다섯 리뷰가 모두 승인되면 전체 승인 완료 상태를 표시한다. 개발자 모드에 새로 진입할 때마다 승인 상태는 초기화한다.

## 개별 승인 흐름

- 승인 상태는 현재 개발자 모드 세션에 한정된 AI 인덱스 집합으로 관리한다.
- 승인하지 않은 AI에서 `APPROVE ♥`를 누르면 해당 AI만 승인 상태가 된다.
- 승인된 AI 카드는 기존 `APPROVED` 메시지를 계속 보여준다.
- 승인된 AI를 다시 선택하면 버튼은 `APPROVED ✓`로 표시되고 비활성화된다.
- 이미 승인된 AI에 대해서는 승인 처리와 폭죽을 다시 실행하지 않는다.
- 승인하지 않은 다른 AI를 선택하면 버튼을 다시 사용할 수 있다.

## 진행 상태와 전체 완료

- 개별 승인 후 `200 OK — {AI 이름} 리뷰 승인 완료 · N / 5 approved`를 표시한다.
- 다섯 AI가 모두 승인되면 자동 AI 순환을 중지한다.
- 전체 완료 문구는 `ALL REVIEWS APPROVED — wedding-v1.0 is ready to merge ♥`로 표시한다.
- 전체 완료 후에도 각 AI 카드를 직접 선택해 승인 메시지를 확인할 수 있다.

## 초기화 정책

- 일반 모드로 전환할 때 화면의 승인 표시를 숨긴다.
- 다음 개발자 모드 진입을 시작할 때 승인 집합, AI 선택 상태, 카드 승인 메시지, 버튼 문구, 전체 완료 문구를 초기화한다.
- 페이지 저장소나 브라우저 저장소에는 승인 상태를 기록하지 않는다.

## 구동 완료 전환

- 마지막 `SUCCESS wedding-v1.0 deployed ♥` 로그가 출력된 뒤 1초 동안 터미널을 유지한다.
- 이후 기존 0.45초 페이드아웃을 거쳐 `Invitation` 본문을 표시한다.
- 움직임 최소화 설정에서는 대기와 애니메이션을 생략한다.

## 접근성과 검증

- AI 선택 버튼의 접근성 이름에 승인 완료 여부를 반영한다.
- 비활성화된 승인 버튼은 실제 `disabled` 상태를 사용한다.
- 기존 폭죽은 신규 AI 승인 시에만 실행한다.
- 다섯 AI 승인, 중복 승인 차단, 개발자 모드 재진입 초기화, 1초 전환 대기를 자동 테스트와 모바일 브라우저에서 검증한다.
- 일반 모드, 통합 구동 화면, 지도, 갤러리, 계좌 기능은 변경하지 않는다.
