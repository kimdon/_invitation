# AI 리뷰 최종 승인 설계

## 목표

개발자 모드에서 다섯 AI의 승인된 리뷰를 기본으로 보여주고, 사용자가 결혼 릴리스 전체를 한 번만 최종 승인할 수 있게 한다. 개발자 모드에 새로 진입할 때마다 사용자의 최종 승인 상태는 초기화한다.

## AI 리뷰 기본 상태

- 다섯 AI 카드는 모두 기존 `APPROVED` 리뷰 문구를 기본으로 보여준다.
- AI 선택 버튼은 모두 승인 완료 상태로 표시한다.
- 사용자는 AI 선택 버튼으로 각 승인 리뷰를 자유롭게 확인할 수 있다.
- 사용자 최종 승인 전에는 기존 자동 AI 순환을 유지한다.

## 사용자 최종 승인

- 공통 버튼은 `APPROVE ♥`로 표시하며 결혼 릴리스 전체에 대한 최종 승인 기능을 담당한다.
- 사용자가 버튼을 누르면 폭죽을 한 번 실행하고 자동 AI 순환을 중지한다.
- 버튼은 `APPROVED ✓`로 변경하고 실제 `disabled` 상태로 만들어 중복 승인을 차단한다.
- 완료 문구는 `FINAL APPROVAL COMPLETE — wedding-v1.0 is ready to merge ♥`로 표시한다.
- 최종 승인 후에도 각 AI 카드를 직접 선택해 승인 리뷰를 확인할 수 있다.

## 초기화 정책

- 일반 모드로 전환할 때 최종 승인 완료 문구를 숨긴다.
- 다음 개발자 모드 진입을 시작할 때 사용자 최종 승인 상태, AI 선택 상태, 버튼 문구, 완료 문구를 초기화한다.
- AI 리뷰의 기본 승인 상태는 항상 유지한다.
- 페이지 저장소나 브라우저 저장소에는 최종 승인 상태를 기록하지 않는다.

## 구동 완료 전환

- 마지막 `SUCCESS wedding-v1.0 deployed ♥` 로그가 출력된 뒤 1초 동안 터미널을 유지한다.
- 이후 기존 0.45초 페이드아웃을 거쳐 `Invitation` 본문을 표시한다.
- 움직임 최소화 설정에서는 대기와 애니메이션을 생략한다.

## 접근성과 검증

- AI 선택 버튼의 접근성 이름은 승인된 리뷰임을 명시한다.
- 최종 승인 후 버튼은 실제 `disabled` 상태를 사용한다.
- 기존 폭죽은 사용자 최종 승인 시 한 번만 실행한다.
- 기본 승인 리뷰 노출, 최종 승인 중복 차단, 개발자 모드 재진입 초기화, 1초 전환 대기를 자동 테스트와 모바일 브라우저에서 검증한다.
- 일반 모드, 통합 구동 화면, 지도, 갤러리, 계좌 기능은 변경하지 않는다.
