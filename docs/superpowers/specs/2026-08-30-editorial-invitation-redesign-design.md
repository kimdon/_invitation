# 모바일 청첩장 에디토리얼 리디자인 명세

## 목표

첨부 HTML의 다크 브라운·아이보리 에디토리얼 디자인과 상호작용을 현재 모바일 청첩장에 적용한다. 결과물은 별도 전용 런타임 없이 GitHub Pages에서 동작하는 순수 HTML, CSS, JavaScript로 유지한다.

## 접근 방식 결정

검토한 방식은 다음 세 가지다.

1. 첨부 HTML을 그대로 교체: `x-dc`, `sc-if`, `sc-for`, `DCLogic`, `image-slot`과 `support.js`가 필요해 현재 저장소와 GitHub Pages에서 독립 실행할 수 없다.
2. 시각 스타일만 반영: 구현량은 적지만 계좌 모달, 복사, 사진 확대, 스와이프 등 첨부 코드의 핵심 경험이 빠진다.
3. 현재 구조로 완전 변환: 첨부 디자인과 기능을 표준 HTML/CSS/JavaScript로 옮기면서 기존 테스트 가능한 유틸리티를 유지한다.

3번을 채택한다. 새 프레임워크나 런타임을 추가하지 않고 기존 파일 경계를 따른다.

## 화면 구조

최대 너비 430px의 단일 열 화면이며 다음 순서로 구성한다.

1. 풀 뷰포트 표지: 대표 사진 자리, 영문 이름 `Byeong-gwan & Do-eun`, 날짜, 스크롤 유도 화살표
2. Invitation: 초대 문구와 양가 부모·신랑·신부 정보
3. When & Where: 다크 배경의 예식 정보와 2026년 11월 달력, D-day
4. Gallery: 3열 사진 그리드, 9장 단위 페이지 이동, 사진 확대 보기
5. Location: 예식장명, 정확한 도로명 주소, 지도 자리, 카카오맵·네이버지도 버튼, 교통·주차 정보
6. Thanks to: 신랑측·신부측 계좌 버튼과 계좌 목록 모달
7. 푸터: `B & D`, `THANK YOU`

## 시각 기준

- 전체 배경: 웜 베이지 `#eae4da`
- 본문 배경: 아이보리 `#f4efe7`
- 다크 섹션: 브라운 블랙 `#1c1916`
- 골드 포인트: `#b39a6e`, 강조 `#d3b788`
- 기본 서체: `Noto Serif KR`
- 영문 장식 서체: `Cormorant Garamond`
- 표지는 640px 이상, 820px 이하의 화면 높이를 사용하고 하단에 이름과 날짜를 배치한다.
- 430px 이하에서는 화면 폭에 맞추며 가로 스크롤을 만들지 않는다.
- 첨부 코드의 인라인 스타일은 유지보수를 위해 `styles.css`의 의미 있는 클래스로 옮긴다.

## 구성 요소와 데이터 흐름

### 정적 문서

`index.html`은 섹션, 모달, 사진 뷰어, 토스트의 접근 가능한 마크업을 제공한다. 이름, 가족 정보, 예식장과 주소는 현재 확정된 값을 유지한다.

### 스타일

`styles.css`가 색상, 타이포그래피, 반응형 레이아웃, 모달, 사진 뷰어와 애니메이션을 담당한다. `prefers-reduced-motion`에서는 등장·꽃잎 애니메이션을 비활성화한다.

### 로직

`src/invitation.js`는 날짜, 달력, 지도 URL처럼 DOM과 분리해 테스트할 수 있는 계산을 유지한다. `src/app.js`는 다음 UI 상태와 이벤트를 관리한다.

- 갤러리 현재 페이지와 페이지 이동
- 확대 사진의 현재 인덱스와 이전·다음 이동
- 신랑측 또는 신부측 계좌 모달 열기·닫기
- 계좌번호 클립보드 복사와 성공 토스트
- 스크롤 진입 애니메이션과 장식 꽃잎

상태는 현재 페이지 안에서만 유지하며 외부 저장소나 서버를 사용하지 않는다.

## 자산 처리

- 첨부 코드의 `image-slot`은 표준 `<img>` 또는 명확한 자리표시자로 변환한다.
- 실제 대표 사진과 갤러리 사진이 저장소에 없으면 깨진 이미지 아이콘을 노출하지 않고 자리표시자를 표시한다.
- 향후 `images/cover.webp`, `images/gallery/01.webp` 형식으로 파일을 추가하면 같은 구조에서 사용할 수 있게 한다.
- 카카오 지도 SDK와 API 키는 기존 합의대로 도입하지 않는다. 두 지도 버튼은 `보타닉 웨딩파크` 검색 화면을 새 탭으로 연다.

## 계좌 모달

- 기본 화면에는 `신랑측 계좌번호`, `신부측 계좌번호` 버튼만 표시한다.
- 각 버튼은 해당 3명의 임시 계좌를 하단 모달에 표시한다.
- 각 계좌에는 역할, 은행, 번호, 예금주와 복사 버튼을 제공한다.
- 모달 바깥 영역, 닫기 버튼, `Escape` 키로 닫을 수 있다.
- 모달이 열려 있는 동안 배경 스크롤을 잠근다.

## 사진 뷰어

- 썸네일 선택 시 전체 화면 다크 뷰어를 연다.
- 이전·다음 버튼, 좌우 키, 모바일 좌우 스와이프를 지원한다.
- 실제 파일이 없는 사진은 자리표시자 상태를 명확히 보여준다.
- 뷰어 바깥 영역, 닫기 버튼, `Escape` 키로 닫을 수 있다.

## 오류 처리와 접근성

- 클립보드 API가 없거나 실패하면 숨은 텍스트 영역을 이용한 복사 방식으로 대체한다.
- 외부 지도 링크에는 `target="_blank"`와 `rel="noopener noreferrer"`를 적용한다.
- 모든 조작 요소에는 접근 가능한 이름을 제공한다.
- 모달과 사진 뷰어는 적절한 dialog 의미, 포커스 가능한 닫기 버튼과 키보드 조작을 제공한다.
- 자바스크립트가 비활성화돼도 핵심 예식 정보, 주소와 지도 링크는 읽을 수 있다.

## 검증 기준

- 기존 달력, D-day와 지도 URL 테스트가 계속 통과한다.
- 새 테스트는 다크·아이보리 섹션 구조, 계좌 모달 2개와 6명 정보, 지도 주소, 사진 뷰어 마크업을 검증한다.
- 클립보드용 계좌 문자열과 페이지 계산은 가능한 범위에서 DOM 독립 함수로 검증한다.
- 375x844 및 430px 폭에서 가로 넘침이 없는지 확인한다.
- 브라우저에서 갤러리 페이지 이동, 모달 열기·닫기, 계좌 복사, 사진 뷰어와 지도 링크를 확인한다.
- 브라우저 콘솔 오류가 없어야 한다.

## 제외 범위

- 카카오·네이버 지도 SDK와 API 키 연동
- 실제 사진 파일 제작 또는 선정
- 실제 계좌번호 입력
- 외부 백엔드, RSVP, 방명록, 결제 기능
